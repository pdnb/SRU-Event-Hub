# แผนการพัฒนาแบ่งระยะ (Roadmap)

ระบบตาม Master Prompt มีขนาดใหญ่ (30+ โมดูล) จึงพัฒนาเป็นระยะ แต่ละระยะส่งมอบซอฟต์แวร์ที่ใช้งานได้จริง ผ่านการทดสอบ และมี migration ของตนเอง

| ระยะ | ขอบเขต | สถานะ |
|---|---|---|
| **P1 Foundation** | Monorepo, infra (Docker/Nginx), Auth (password + Google OIDC, refresh rotation, lockout), RBAC + Data Scope, หน่วยงาน, ผู้ใช้, ประเภท/หมวดหมู่, กิจกรรม + state machine, Workflow อนุมัติแบบกำหนดเอง, Portal สาธารณะ (ค้นหา/กรอง/ปฏิทิน/แชร์), ลงทะเบียนรายบุคคล (atomic, idempotent, waitlist, guest, ตรวจสถานะด้วย token), Export Excel/CSV, Audit log, utility การเงิน (บาทถ้วน, PromptPay, ปีงบประมาณ) | ✅ เสร็จ |
| **P2a Payment core** | อัตราค่าลงทะเบียน (ตามประเภท/ช่วงเวลา, snapshot), ใบแจ้งชำระ + PromptPay QR, แนบสลิป (magic number, private bucket, SHA-256 ซ้ำ), ตรวจ/ไม่ผ่าน/ยกเว้น (SoD), หมดเวลา (BullMQ delayed + sweeper) + เลื่อนรายชื่อสำรอง, ledger append-only + trigger ห้ามแก้ยอด, ขั้นตรวจสอบการเงินในการอนุมัติ, ชุดนำส่งกองคลัง + Excel, เลขที่ใบเสร็จ, บัญชีรับเงิน/รหัสรายได้ | ✅ เสร็จ |
| **P2b Finance operations** | กะรับเงินหน้างาน (เปิด/รับเงิน/ยกเลิกรายการ/ปิดกะนับเงิน/นำส่ง/ยืนยันยอด), คืนเงิน (ขอ/อนุมัติ/จ่าย, เลขบัญชีเข้ารหัส), ยกเลิกเลขที่ใบเสร็จ, Audit log UI, ตั้งค่าระบบ, Redis-backed throttling, ESLint | ✅ เสร็จ |
| **P2c Finance (ตั้งค่าได้ รอแบบฟอร์มจริง)** | รายงานนำส่ง/ใบนำส่งเงิน PDF + Excel จากแม่แบบใน system_settings (FIN-1), กระทบยอดกับ statement ธนาคาร (CSV/XLSX, จับคู่อัตโนมัติ/ด้วยมือ, รายงานส่วนต่าง), แก้อัตราหลังอนุมัติ → อนุมัติใหม่ (FEE_CHANGE), ข้อมูลออกใบเสร็จนิติบุคคล (FIN-9), โหมดออฟไลน์ที่จุดรับเงิน + รายชื่อสำรองกระดาษ (FIN-12) | ✅ เสร็จ (ค่าชั่วคราว — ปรับแม่แบบเมื่อได้คำตอบ FIN-1/8/9/12) |
| **P3a Group Registration (backend)** | องค์กรผู้ส่งเข้าร่วม + ผู้ประสานงาน, ตั้งค่ากลุ่มต่อกิจกรรม, กลุ่มฉบับร่าง, เพิ่มสมาชิกเอง/ลิงก์เชิญ/นำเข้า Excel (ตรวจก่อน-ยืนยันทีหลัง), ส่งกลุ่ม = สำรองที่นั่งทั้งกลุ่มแบบ atomic + ใบแจ้งชำระรวม (payment_order_lines), เปลี่ยนตัว/เพิ่ม/ถอนหลังส่ง (ออกใบแจ้งใหม่), หมดเวลาทั้งกลุ่ม, ยกเลิกกลุ่ม → คืนเงิน, PDPA consent (ผู้ประสานงานรับรอง + สมาชิกยินยอมเอง), change log append-only | ✅ เสร็จ |
| **P3b Group Registration (web) + สมัครสมาชิก** | หน้าผู้ประสานงาน (/my/groups: องค์กร, กลุ่ม, สมาชิก, นำเข้า Excel, ลิงก์เชิญ, ส่งกลุ่ม, ชำระเงินรวม, ประวัติ), การ์ด "ลงทะเบียนแบบกลุ่ม" ในหน้ากิจกรรม, หน้าเปิดลิงก์เชิญ (/group-invite), หน้าผู้จัด (แท็บกลุ่มในกิจกรรม: ตั้งค่า + รายการ, /admin/groups/:id, /admin/participant-orgs ตรวจสอบองค์กร), สมัครสมาชิกเอง + ยืนยันอีเมล (/register, /verify-email; SMTP ผ่าน `SMTP_URL`) | ✅ เสร็จ |
| **P4 Check-in & Badges** | QR token (HMAC, เก็บเฉพาะ hash, ออกใหม่ได้), สแกนด้วยกล้อง/เครื่องสแกน/ค้นชื่อ, หลายจุด + ช่วงกิจกรรม (session), กันเช็กอินซ้ำข้ามจุด (row lock), เช็กเอาต์, ยกเลิกรายการ, ออฟไลน์ + sync, real-time (Socket.IO + Redis adapter), QR กลุ่ม + เช็กอินทั้งกลุ่ม, Attendance (แก้ไขด้วยมือ + export), บุคลากรของงาน, Template designer + PDF engine (A4 หลายป้าย/เครื่องพิมพ์บัตร), พิมพ์ป้ายชื่อชุด/ทันที/ซ้ำ (บันทึกทุกป้าย, พิมพ์ซ้ำต้องมีสิทธิ์+เหตุผล) | ✅ เสร็จ (รูปแบบป้ายรอ BDG-1..4, กติกาเช็กอินรอ CHK-1..5) |
| **P5a Certificates & Evaluation** | แบบประเมิน (สร้าง/เผยแพร่/ปิด, คำถาม 5 ชนิด, ไม่ระบุตัวตน + ตอบได้ครั้งเดียว, เฉพาะผู้เช็กอิน, สรุปผล ค่าเฉลี่ย/S.D./ระดับ + Excel), เกียรติบัตร (designer ใช้ canvas ร่วมกับป้ายชื่อ, ภาพพื้นหลัง, เกณฑ์: เช็กอิน/นับมาสาย/% ช่วงกิจกรรม/ตอบแบบประเมิน, ผู้รับเป็นผู้เข้าร่วมหรือบุคลากรตามบทบาท), ออกชุด/รายคน/ยกเว้นเกณฑ์พร้อมเหตุผล, ผู้เข้าร่วมรับเองเมื่อผ่านเกณฑ์ (รวม guest), ยกเลิก + ออกใหม่, ทะเบียน Excel / PDF รวม, ตรวจสอบสาธารณะด้วยรหัส 12 หลัก/QR | ✅ เสร็จ (เกณฑ์รอ CHK-2/3, CERT-1..4, EVAL-1) |
| **P5b Venues & Notifications** | สถานที่/อุปกรณ์/อาคาร (หน่วยงานผู้ดูแล, อนุมัติอัตโนมัติ), ตารางว่างรายวัน, ขอจองสถานที่/ยืมอุปกรณ์ (ผูกกิจกรรมหรือใช้งานทั่วไป), อนุมัติ/ไม่อนุมัติ (SoD, ตามขอบเขตหน่วยงาน), กันจองซ้อนระดับฐานข้อมูล (EXCLUDE + trigger จำนวนคงเหลือ), ยกเลิกกิจกรรม → ปล่อยการจอง · การแจ้งเตือนในระบบ + อีเมล + LINE (Messaging API, เชื่อมบัญชีด้วยรหัสครั้งเดียว), dispatcher จาก audit log (ส่งเฉพาะสิ่งที่ commit แล้ว, ไม่ซ้ำ), outbox + retry, เตือนก่อนวันงาน, ตั้งค่าช่องทางรายบุคคล, ประวัติการส่ง + แม่แบบข้อความแก้ได้ | ✅ เสร็จ (นโยบายรอ VEN-1/2, NOTI-1/2) |
| **P5c Dashboards, Reports, Playwright** | Dashboard ตามบทบาท, รายงาน (กิจกรรม/ผู้เข้าร่วม/การเงิน/ความพึงพอใจ), Playwright E2E | |
