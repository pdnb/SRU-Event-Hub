# ประเด็นที่ต้องยืนยัน (Open Questions)

สถานะ: ⏳ รอคำตอบ · ✅ ตอบแล้ว — เมื่อได้คำตอบให้บันทึกผู้ตอบและวันที่

## กองคลัง (spec §4.7.9)
| # | คำถาม | ผลต่อระบบ | สถานะ |
|---|---|---|---|
| FIN-1 | แบบฟอร์มรายงานนำส่งและใบนำส่งเงินที่ใช้อยู่จริง | แม่แบบ `finance.remittanceReportTemplate` / `finance.cashRemittanceTemplate` (P2c ใช้แบบชั่วคราว แก้ได้ที่หน้าตั้งค่าระบบ) | ⏳ |
| FIN-2 | รูปแบบเลขที่ใบเสร็จ (เล่มที่/เลขที่) และการใช้ e-Receipt | `receipt_records` unique (ปีงบ, เล่ม, เลขที่) | ⏳ |
| FIN-3 | ระยะเวลาส่งรายงานล่วงหน้าก่อนวันจัด | `system_settings.finance.submissionLeadDays` (ค่าชั่วคราว 7 วัน) | ⏳ |
| FIN-4 | บัญชีรับเงินกลางหรือแยกหน่วยงาน, อนุญาต PromptPay หรือไม่ | `bank_accounts`, การแสดง QR, ผู้มีสิทธิ์กระทบยอด (บัญชีกลางต้องมีสิทธิ์ระดับมหาวิทยาลัย) | ⏳ |
| FIN-5 | รหัสรายได้ / แหล่งเงิน | `income_codes` seed | ⏳ |
| FIN-6 | ผู้ตรวจสอบสลิป (หน่วยงานผู้จัด หรือ กองคลัง) | สิทธิ์ `payment:verify` | ⏳ |
| FIN-7 | ระยะเวลานำส่งเงินสดหลังรับหน้างาน | แจ้งเตือนใบนำส่ง | ⏳ |
| FIN-8 | ระเบียบยกเลิกใบเสร็จและคืนเงิน | workflow refund | ⏳ |
| FIN-9 | ภาษีกรณีออกใบเสร็จในนามนิติบุคคล | `payment_orders.billing_*` (P2c เก็บชื่อ/เลขผู้เสียภาษี/สาขา/ที่อยู่ ยังไม่คำนวณภาษี) | ⏳ |
| FIN-10 | ใบเสร็จฉบับเดียวในนามองค์กรสำหรับหลายคน, เอกสารประกอบเบิกจ่าย | รูปแบบใบเสร็จกลุ่ม | ⏳ |
| FIN-11 | ระยะเวลาเก็บรักษาข้อมูลการเงิน | นโยบาย retention | ⏳ |
| FIN-12 | แนวทางบันทึกสำรองเมื่อเครือข่ายขัดข้องที่จุดรับชำระ | P2c: คิวในเครื่อง + sync (ภายใน 72 ชม.), รายชื่อสำรองกระดาษ — รอยืนยันว่าระเบียบยอมรับหรือไม่ | ⏳ |
| FIN-13 | รูปแบบไฟล์ statement ของธนาคารที่ใช้ (CSV/Excel, หัวคอลัมน์, การเข้ารหัสอักษร) | `finance.statementColumns`, `finance.reconcileToleranceMinutes` | ⏳ |
